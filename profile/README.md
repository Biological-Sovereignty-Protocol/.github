## 🧬 What is BSP?

The **Biological Sovereignty Protocol (BSP)** is an open, decentralized standard for the permanent ownership and secure exchange of biological data. Built on Arweave and SmartWeave, the protocol ensures that individuals have absolute cryptographic sovereignty over their biomarkers, clinical records, and vitality data.

By eliminating health data silos, BSP enables a direct, zero-trust connection between humans and the institutions driving the future of longevity and precision medicine.

## 🏗️ Core Architecture

<table>
  <tr>
    <td width="50%">
      <h3>👤 Biological Entity Objects (BEO)</h3>
      <p>Permanent, cryptographically secure digital identities for human beings. Each BEO is owned by a private key, and supports advanced features like Social Recovery via Shamir Secret Sharing.</p>
    </td>
    <td width="50%">
      <h3>🏥 Institutional Entity Objects (IEO)</h3>
      <p>Identities for laboratories, hospitals, wearables, and platforms. IEOs undergo certification via decentralized governance to interact with the BSP ecosystem.</p>
    </td>
  </tr>
  <tr>
    <td width="50%">
      <h3>🔐 ConsentTokens</h3>
      <p>Granular, cryptographically signed permissions granted by a BEO to an IEO. Defines exactly who can access what data, for how long, and for what purpose (Intents).</p>
    </td>
    <td width="50%">
      <h3>📜 BioRecords</h3>
      <p>Standardized, encrypted biological data packages stored permanently on Arweave. Accessible only by the BEO owner and institutions holding a valid, unrevoked ConsentToken.</p>
    </td>
  </tr>
</table>

## 🚀 Key Repositories

- 📦 **[@bsp/sdk](https://github.com/Biological-Sovereignty-Protocol/bsp-sdk-typescript)**: The official TypeScript SDK. The standard gateway for Node.js and browser applications to interact with the protocol.
- 📦 **[@bsp/python-sdk](https://github.com/Biological-Sovereignty-Protocol/bsp-sdk-python)**: The official Python SDK, designed for data scientists, longevity researchers, and AI agents.
- ⚡ **[bsp-mcp](https://github.com/Biological-Sovereignty-Protocol/bsp-mcp)**: Model Context Protocol (MCP) server that gives AI Assistants deep native integration with the BSP ecosystem.

> *Note: The core SmartWeave contracts (`bsp-registry`) are maintained by the Ambrosio Institute at `Ambrosio-Institute/bsp-registry`.*

## 🌐 Ecosystem Capabilities

- **For Individuals:** Absolute ownership of clinical data. Easily share your full biological history with a new doctor or longevity clinic in seconds. Revoke access instantly.
- **For Laboratories:** Issue test results directly to the patient's permanent record. No more expensive integrations with hundreds of different clinical systems.
- **For Researchers:** Request anonymized aggregate datasets across millions of BEOs, accelerating research while perfectly preserving privacy.
