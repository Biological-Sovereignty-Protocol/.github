## Repository Descriptions (Settings > About > Description)

**bsp-spec:**
> Open protocol specification for sovereign biological data exchange — BEO, IEO, BioRecord, ConsentToken, and the complete biomarker taxonomy.

**bsp-sdk-typescript:**
> Official TypeScript/JavaScript SDK for the Biological Sovereignty Protocol. Build health apps with sovereign biological data.

**bsp-sdk-python:**
> Official Python SDK for the Biological Sovereignty Protocol. Built for data scientists, researchers, and AI engineers.

**bsp-mcp:**
> MCP server that connects Claude, ChatGPT, and AI assistants natively to BSP biological data.

**bsp-id-web:**
> Reference web application for BSP identity creation, consent management, and biological data dashboard.

**bsp-docs-repo:**
> Official documentation for the Biological Sovereignty Protocol — quickstarts, implementation guides, API reference, and whitepaper.
