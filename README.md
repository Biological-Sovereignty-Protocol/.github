# Biological Sovereignty Protocol `.github` Repository

This repository acts as the **central community health and standard hub** for the Biological Sovereignty Protocol (BSP) open-source organization.

GitHub uses this specific repository to enforce organization-wide defaults.

## What's Inside?

1. **`profile/README.md`**: The landing page shown when anyone visits `github.com/Biological-Sovereignty-Protocol`. Showcases our architecture (BEOs, IEOs), ecosystem repos, and mission.
2. **`CODE_OF_CONDUCT.md`**: The standard rules of interaction to ensure a safe, welcoming environment for researchers and developers.
3. **`CONTRIBUTING.md`**: Architectural philosophy and guidelines for contributing to our SmartWeave contracts, SDKs, and APIs.
4. **`SECURITY.md`**: Strict vulnerability disclosure processes, highly critical given the sensitive biological data our protocol secures via Ed25519 and Arweave.
5. **Issue & PR Templates**: Standardized markdown templates ensuring contributors map bugs and feature requests to specific components in our stack.

## Editing these assets

Changes made to `.github/` files here will automatically propagate as the default for all other repositories in this organization unless overridden locally.
